# Пять торговцев Аргента — City Shops01

Добавляет пять НПС в точные точки, указанные владельцем. Все пять проверены
как сухие клетки безопасной зоны Аргента; ближайший существующий НПС не ближе4.7м.
Расстояние1м между двумя последними точками — явный выбор владельца.

Всего632позиции. Полный перечень с настоящими ID/названиями — `catalog.json`.
Для фей включены только улучшенные статовые фрукты276–280: при успешном росте
дают +2 к одной характеристике. Простые фрукты +1 исключены. Мордо/Junior
и их яйца стоят20000G; обычные феи2000G. Родные условия роста/сытости/использования
сохраняются. ЗЯ повышает дроп, НЯ — опыт; это разные эффекты.

Аппарели отобраны из существующей экипировки с нулевым требуемым уровнем и без
ограничения профессии, плюс все крылья типа44. Технические записи причёсок Hair
исключены. Ограничения расы/профессии/перерождения самих вещей не снимаются.
Чёрные драконьи и другие редкие гемы не добавлены как «базовые»: здесь пять
простых статовых гемов. Билеты сохраняют родные условия и направления; покупка
билета не открывает недоступную карту. Декоративные модели без предмета в
ItemInfo в магазин не выдумываются.

## Установка одним комплектом с ботами

1. Останови ботов и сохрани копию своей `data`. Скопируй весь комплект Alpha46
   поверх своей программы. Промежуточные Alpha45 и другие патчи не нужны.
2. Останови GameServer обычным способом.
3. Открой `server-shops/Install-City-Shops.cmd`. Укажи папку GameServer или
   серверную `resource`. Пять координат из таблицы уже настроены.
4. Установщик сделает резервные копии и добавит НПС. Перезапусти сервер.
   После входа поговори с торговцами. Товары продаются через страницы диалога,
   по одной вещи за нажатие; цена написана у каждого пункта. Есть Next/Previous.
5. Запусти обновлённых ботов через `Start-World.cmd`.

Установка не требует изменения SQL/аккаунтов/персонажей/клиента. Она не меняет
`data` ботов, рейты, квестовые награды и глобальные цены ItemInfo.
В текущей версии новые магазины используют собственные пункты диалога;
автоматическая покупка ботами через стандартное окно Trade к ним не подключена.
Старые магазины и их покупки ботами сохраняются.

Серверный патч отдельно изменяет ровно четыре файла:
- `resource/script/MisScript/NpcScript01.lua`: в конец добавляются собственные функции.
- `resource/script/MisSdk/NpcSdk.lua`: одна ветка обработки покупок новых торговцев.
- `resource/garner/garnernpc.txt`: пять новых строк.
- `resource/garner/garnerNPC.bin`: пять новых записей; существующие записи точны побайтно.

Резервные копии: `resource/owner-city-shops-backups/<дата>/`.
Контроль установки: `resource/owner-city-shops-v1.json`.
Повторный запуск с той же точкой не создаёт копии НПС. Если файлы изменили после
установки, автоматическая перезапись останавливается. При частичном сбое
изменённые ресурсы откатываются. Для ручного отката останови GameServer,
верни четыре файла из одной резервной папки и убери контрольную запись установки.
Не заменяй остальные серверные файлы и не удаляй данные персонажей.

Цены действуют только у новых торговцев. Проверяются деньги и место; покупка
получает настоящий предмет, списывает настоящие деньги. При отказе выдачи
возвращается только действительно списанная сумма. Общего лимита покупателей,
запасов или задержки НПС нет. Неожиданные движковые ошибки журналируются,
не вызывая слепой повторной выдачи предмета/денег.

сохранение старых записей/цен, резервирование, повтор установки и откат сбоя.
На отдельной копии загруженных ресурсов подтверждено152→157НПС, побайтовая
сохранность старых записей и синтаксис обоих полных Lua после патча.
На живом Windows GameServer патч ещё не проверен.
Оригинальные серверные Lua/таблицы/бинарники и личные данные в комплект не входят.
