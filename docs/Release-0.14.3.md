# Four Fronts Frenzy 0.14.3-alpha

[Скачать карту](../releases/FourFrontsFrenzy-0.14.3-alpha.w3x).

Лимит одновременно живых обычных солдат увеличен с 48 до **60 на игрока**, то есть до **180 на команду** из трёх игроков. Герои и призванные существа в этот лимит не входят.

У каждой занятой команды теперь один общий магазин книг вместо трёх. Все активные игроки команды используют один магазин через `-books`; полностью пустая команда не получает магазин. Ряд магазинов собран без промежутков: пять обычных, сокровищница, книги и припасы. Цены книг сохранены.

При заполнении лимита волны приостанавливаются. Если живы 59 бойцов, следующая волна добавляет только одного. После потерь освободившиеся места заполняются в следующие обычные волны. Изменение одинаково для людей и ботов. Интервал 21 секунда, размер волн и его платная прокачка сохранены.

Исправление выбора всех героев из [0.14.2](Release-0.14.2.md) и баланс [0.14.1](Release-0.14.1.md) сохранены. Требуется новая игра на новой версии карты.

Проверки: полный `npm test`, включая границу 59→60, повторный спавн при полном лимите, заполнение армии каждого из 12 игроков и пополнение после потери бойца; один магазин на команду, общие ссылки для трёх игроков, пустые слоты и проходимость восьми магазинов в ряду; строгий legacy pjass. Бинарные данные способностей, юнитов и предметов сравниваются с предыдущими версиями, исследования отличаются только текстом нового предела. Warcraft III здесь не запускался; производительность с большим числом бойцов нужно проверить в игре 1.26.
