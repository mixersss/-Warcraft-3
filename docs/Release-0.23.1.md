# Four Fronts Frenzy 0.23.1 — музыка

[Скачать карту](../releases/FourFrontsFrenzy-0.23.1-alpha.w3x). Для Warcraft III Classic1.26; начать новую игру.

Встроены восемь разных присланных записей целиком, в порядке прикрепления. Повторный файл «Экзамен с ответами» исключён по просьбе пользователя. Музыка запускается автоматически с начала матча; после восьмой записи повторяется первая. Названия этапов в файлах здесь служат только названиями: в Footman это один общий плейлист.

1. Экзамен с ответами.mp3 — 1:43.
2. Takanashi_Yasuharu_-_A_Friend_s_Reminiscence_(Bib.fm).mp3 — 2:06.
3. Поиск саске и финальные битвы.mp3 — 3:16.
4. 1 этап.mp3 — 2:06.
5. Финальные бои на арене.mp3 — 2:01.
6. Первые бои на арене.mp3 — 2:44.
7. Второй этам со свитками.mp3 — 3:13.
8. Второй этап со свитками.mp3 — 2:45.

Полные композиции перекодированы в MP3,24кбит/с,22050Гц,моно. Карта7018551байт (6,69МиБ), ниже лимита8МиБ Classic1.26. Исходные хэши, длительности и готовые файлы находятся в map/music.json и map/music/. Сборка не требует исходных загрузок пользователя.

Один таймер переиспользуется для смены песен; пользовательская громкость музыки сохраняется. Игровые объекты, герои, способности, ИИ, цены, баланс, спавн и ландшафт совпадают с0.23.0. Naruto Alpha33 не изменён.

Проверки: полный npm test, строгий Classic pjass; независимый разбор MPQ/каждого4096-байтного сектора и таблицы импорта; точное сравнение всех игровых файлов с опубликованной0.23.0; кодек/полная длительность всех8треков; выполнение настоящих музыкальных callback с native-моками в течение трёх циклов1–8→1, повторная инициализация создаёт ровно один таймер. [Протокол](../releases/FourFrontsFrenzy-0.23.1-verification.json). Воспроизведение и переходы в реальной Warcraft III ещё требуют игрового теста.
