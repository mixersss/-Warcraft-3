# Four Fronts Frenzy 0.20.1-alpha

[Скачать карту](../releases/FourFrontsFrenzy-0.20.1-alpha.w3x). Начать новую игру.

Хранитель рощи теперь призывает энтов **без деревьев**: изучить «Силу природы» и нажать **E**. Энты появляются рядом с героем; выбирать дерево или точку не нужно. Это отдельная нативная способность призыва с прежними энтами. Число бойцов на каждом из 200 рангов, рост здоровья/урона/брони, время жизни, стоимость маны и откаты сохранены. Боты используют новый призыв через общую систему применения способностей.

Все остальные изменения [0.20.0](Release-0.20.0.md) сохранены: расовые особенности, старт по шесть пехотинцев, два режима героев и самостоятельный выбор рас ботами.

Автоматические проверки: сопоставление всех 200 рангов с прежним призывом; отдельное сравнение всех остальных игровых данных и скрипта с опубликованной 0.20.0; штатные проверки карты и приказов ботов, строгий legacy pjass. Движок Warcraft III здесь недоступен: само появление энтов и анимацию нужно проверить в Classic 1.26.
