# Four Fronts Frenzy 0.17.1-alpha

[Скачать карту](../releases/FourFrontsFrenzy-0.17.1-alpha.w3x). Начать новую игру.

Волны солдат появляются каждые **18 секунд вместо 21**. Предел одновременно живых солдат повышен с **60 до 85 на игрока**: до 255 на полную команду и 1020 при 12 занятых слотах. Погибший солдат освобождает место для следующей волны. При приближении к лимиту выходит только оставшееся допустимое количество; переполнения нет.

Размер начальной волны — три солдата; улучшение численности волн сохранено. Стоимость и сила исследований (+4 атаки, +1,5 брони, +10% базового HP), 49 героев, навыки, призывы, предметы, ИИ, доход, автосохранение и ландшафт не менялись. Текст статуса и подсказки используют новые значения.

Проверки: полный `npm test`, строгий legacy pjass, независимая сверка с опубликованной 0.17.0. Изменены только три константы, версия и связанные подсказки. Игровой harness проверяет таймер между волнами, лимит у всех 12 игроков, частичную последнюю волну, освобождение места после гибели и последующий спавн. Исторические проверки допускают только эту конкретную поправку настроек и соответствующих подсказок через `historical-wave-settings.cjs`; `verify-0171.cjs` отдельно сверяет исходный опубликованный архив без такого преобразования.

Warcraft III здесь не запускался; реальная загрузка и производительность массовых сражений требуют проверки в 1.26.
