# Four Fronts Frenzy 0.14.2-alpha — исправление выбора героев

[Скачать карту](../releases/FourFrontsFrenzy-0.14.2-alpha.w3x).

В прежней галерее восемь портретов занимали верхние два ряда. Штатная кнопка флага сбора Warcraft III (ARal) находится в столбце 4, ряду 2 и перекрывала восьмой портрет — в том числе Алхимика на странице 3. Наличие героя в списке обучения не доказывало, что его кнопка видна. Ошибка подтверждена скриншотом пользователя и штатными данными ARal (buttonpos_1=3, buttonpos_2=1).

Теперь на странице семь портретов; место флага оставлено свободным. Всего шесть страниц, все 36 героев сохранены. **Алхимик: страница 4/6, верхний ряд, третий слева.** Также исправлены страницы, где скрывались другие восьмые портреты. Четыре нижние кнопки навигации сохранены. Подсказки карточек теперь показывают действующие 200 рангов обычных навыков.

До старта боя можно выбрать Алхимика командой `-hero alchemist`; выбор доступен в обычном режиме в первые 60 секунд. Для обновления галереи требуется новая игра на версии 0.14.2.

Баланс, ауры и способности [0.14.1](Release-0.14.1.md), включая Трансмутацию 100+30 за каждый последующий ранг, сохранены. Автоматические проверки включают пересечение всех портретов/управления со штатной ячейкой флага, наличие всех 36 карточек ровно на одной странице, callback выбора каждого героя и переходы между первой/последней страницами. Полный `npm test` и строгий legacy pjass обязательны. Отдельно сопоставляются объекты с 0.14.1: меняются только карточки/страницы выбора. Нативный интерфейс Warcraft III здесь не запускался; следует проверить новую раскладку в игре 1.26.
