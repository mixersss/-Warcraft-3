# Установка Alpha57

1. Останови ботов, **всеGameServer** и клиент.
2. Распакуй полныйAlpha57в новую папку. Скопируй туда **всюdata** из действующей
Alpha56 (или предыдущего полного выпуска), старую папку сохрани.
3. ЗапустиINSTALL-SERVER-SHOPS.cmd. Серверный путь —GameServer/resource;
клиентский —папкаИГРЫ сGame.exeиscripts. Это ставит и серверное исправление
Possession: просто запустить новых ботов недостаточно.
4. В отчёте установки проверьloot_protection.seconds=1. Если вместо этого
requires_manual_configuration=true, выставьitem_prot_time = 1в каждом активном
GameServer*.cfg. **Не0**:0в этой версии означает бессрочную защиту.
5. Перезапусти всеGameServer, затем игру и ботов. Find-Botдолжен показатьAlpha57.

Проверкаbuba: покормиДжун, положи во вторую ячейку, дождись180секунд после прошлого
применения, нажми сам навык. Для6ур./ранг3тратится12сытости, эффект160секунд;
сравни реальные статы и опыт с одинакового моба. Прибавка зависит от статовДжун.
Если статы изменились, а свечения нет, запустиCheck-Fairy-Possession.cmdна папке
ИГРЫ. Если нет обоих эффектов, сохрани точное сообщение системного чата.

Убей обычного моба: Пачкули должны лежать на земле; после1–2секунд их можно
подобрать. Старые предметы, созданные до перезапуска с длинной защитой, этим
тестом не проверяются. Камни выпадают в среднем3из100убийств суммарно, не каждый
вид по3%. Счётчик наНПС2211:2713показывает запросы, а не доказательство подбора.

Сохрани свежиеpopulation-status.jsonи2–3bot-report*.json, если остаются простои.
Пароли, аккаунты/dataцеликом присылать не нужно. Ковка и новая торговая специализация
будут вAlpha58; текущее обновление сохраняет прежние ларьки и диалоги.
