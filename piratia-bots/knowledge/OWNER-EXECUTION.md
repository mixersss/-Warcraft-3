# Исполнение цели владельца: 500 ботов

Авторитетное полное ТЗ: [OWNER-GOAL-500.md](OWNER-GOAL-500.md).
Этот список ведётся по порядку зависимостей. «Код проверен» не означает, что
поведение уже подтверждено на живом сервере. Последний подтверждённый снимок —200ботов. Alpha41 готовит расширение до300
при запуске владельцем; старые200 и весь прогресс сохраняются. Живые300 ещё не подтверждены.

Оружие: последнее уточнение владельца — выбирать лучший комплект, два одноручных
меча либо один двуручный. Не закреплять два меча без сравнения. Учитывать обе руки,
расу, профессию, навыки, урон, скорость, бонусы и сохранность заменяемых предметов.
Alpha41 выполняет базовое сравнение целого комплекта и двухшаговое надевание
двух собственных мечей с native-подтверждением. Полная оптимизация по всем навыкам,
модификаторам и восьми билдам ещё не реализована; сумма оценки не равна точному DPS.

После каждого этапа: локальные регрессии, сохранность data, публикация проверенного
архива на GitHub, затем сопоставление свежих отчётов с ожидаемым поведением.
Сырые отчёты, аккаунты, пароли, исходные карты/серверные Lua остаются частными.
