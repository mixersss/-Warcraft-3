# Alpha50 — один полный комплект

1. Останови ботов, GameServer и клиент Game.exe. Сделай копию папки `data`.
2. Распакуй комплект и скопируй содержимое поверх текущей папки ботов. `data`
   сохрани: аккаунты, персонажи, предметы, классы, билды и прогресс не заменяются.
3. **Обязательно запусти INSTALL-SERVER-SHOPS.cmd — также после Alpha48/49.**
   Укажи серверную `resource` и отдельно папку клиента игры с Game.exe.
   Пример сервера: `C:\PKO138 + Tools\[1] GameServer\resource`.
   Пример клиента: `C:\Games\Пиратия Online`.
4. Дождись завершения установки, затем запусти сервер, клиент и Start-World.cmd.
   Для других клиентов используй UPDATE-CLIENT-PRICES.cmd и перезапусти игру.

Этот шаг устанавливает выкуп Пачкули НПС **по500G за штуку для всех персонажей**.
В классике НПС платит половину базовой цены, поэтому в серверной и клиентской
ItemInfo для ID1000ставится1000. Это не цена500в ларьке: боты теперь Пачкули
продают НПС. Персонаж владельца получает ту же цену. Остальные выбранные цены
магазинов сохраняются. В5магазинах645товаров; синхронизируются646ценовых записей.
Чужие поля предметов, старые NPC, рейты, квестовые награды, SQL и data сохраняются.
Установщик создаёт резервные копии и обновляет справочник ботов.

Новое в ботах:

- Деньги на класс: новичок с Пачкули не остаётся без проезда к наставнику.
- Выбор подходящего классового оружия вместо стартового меча; магические
  классы не подменяют недоступную магию ударом рукой. Покупки оружия/книг/
  кораллов имеют приоритет. Заряд кораллов обновляется отдельным родным пакетом.
- Проверка реального прогресса, короткая попытка выхода с занятой кромки берега,
  быстрое отклонение невозможного пешего пути между раздельными участками суши.
- В ларьках — НП и подходящее снаряжение, включая обычные выпавшие вещи с
  понятными характеристиками. Названия ларьков различаются. Покупки подтверждаются
  сумкой и списанием настоящих денег. Пачкули в ларьки не выставляются.
- НП684: покупка по потребности, настоящая карта682, оплаченный билет2445в Карибы,
  обратный билет, реальные координаты и применение карты. Родной уровень15–40,
  место в сумке, полныеHP/SPдля билетов, ловушки и случайность раскопки сохраняются.
- Общение: местный, мировой, торговый и ЛС; контекст по каналам/собеседникам,
 12характеров, координация ответов и короткие беседы2–4ботов. Игра не ждёт
  окончания беседы. Неизвестные фразы уточняются, а не считаются понятыми.

Configure-Chat.cmd — тихо/обычно/оживлённо, применяется после перезапуска ботов.
Validate-Dialogue.cmd — проверка данных общения. Подробности: knowledge/DIALOGUE50.md.

Через10–15минут проверь рост опыта и атак. При проблеме нужны свежие
population-status.json, bot-diagnostics.log и bot-report-номер.json стоящего бота.
Find-Bot.cmd показывает прогресс, заряд кораллов, пати, диалоги и состояние связи.
Закрытие окна диагностики эти файлы не удаляет. Папку data присылать не нужно.

На живом Windows-сервере Alpha50ещё не проверена. Геометрический повтор свежих
позиций:35нуждаются в восстановлении,11имеют сухой выход,8—короткий физически
проверенный пробный выход,16пока не имеют подходящего выхода. Пробный маршрут
принимает или отклоняет сервер; локальных телепортаций нет. Все простои и
причины периодических разрывов связи не объявляются исправленными без проверки.
