# Пиратия — обход зависания при смене музыки, версия 01

**Фоновая музыка сохраняется.** Программа перекодирует музыкальные MP3 в OGG Vorbis,
сохраняя прежние имена и расположение файлов. Настройку музыки, Game.exe, DLL,
сервер, базы и ботов она не изменяет. WAV-файлы со звуками не обрабатываются.
Исходные MP3 копируются в резервную папку; предусмотрено точное восстановление.

Это проверяемый обход найденного в дампе ожидания в SDL/SMPEG. **Устранение зависания
и воспроизведение на настоящем Windows-клиенте ещё требуется подтвердить.** Другие
возможные причины зависаний этот обход не исправляет.

## Как применить

1. Полностью закрой клиент игры. Сервер и программа ботов могут продолжать работать.
2. Распакуй весь ZIP в отдельную папку, например `C:\PiratiaMusicFix`.
3. Открой **`Apply-Music-Fix.cmd`**. Используется Python, уже установленный для ботов.
4. В окне выбора укажи **папку клиента игры**, где находятся `music`, `scripts`, `system`.
   Например, `C:\Program Files (x86)\Nival Online\Пиратия Online`.
   Не выбирай папку сервера `PKO138 + Tools` или отдельную папку `music`.
5. Если FFmpeg ещё не установлен, программа один раз скачает большой ZIP версии
   7.1.1 с GitHub GyanD. Интернет нужен для этой загрузки. Перед запуском скачанных
   инструментов проверяется SHA-256 из официального манифеста Microsoft WinGet.
   Системная установка FFmpeg и изменение PATH не выполняются.
6. Дождись строки **«Готово»**. Обработка может занять несколько минут.
7. Запусти игру, проверь наличие музыки и сделай 10–15 переходов через границу города.
   Отдельно проверь смену композиции при переходе в другую музыкальную зону.

Если программа сообщает об отсутствии доступа в `Program Files`, закрой её и запусти
`Apply-Music-Fix.cmd` правой кнопкой → **«Запуск от имени администратора»**.
Появление запроса Windows связано с записью в защищённую папку клиента.

Внутри папки клиента появится **`music-backup-before-ogg`**. Сохраняй её:
там оригинальная музыка и список контрольных сумм. Не копируй её содержимое поверх
`music` вручную. Не запускай обработку одновременно с игрой или вторым конвертером.
Если операция прервётся, повторный запуск продолжит её и не перекодирует готовые файлы.
При частичной обработке сначала заверши её или восстанови оригиналы перед игровым тестом.

## Как вернуть оригиналы

Закрой игру, открой **`Restore-Music.cmd`**, выбери ту же папку клиента.
Интернет и FFmpeg для восстановления не нужны. Перед первым восстановлением
проверяются все резервные копии и текущие файлы. Если файл был дополнительно
изменён вручную, программа остановится, чтобы не затереть новую версию.

## Почему имена остаются `.mp3`

Этот старый клиент получает пути к композициям из своих таблиц. Звуковая библиотека
определяет формат по содержимому: заголовок `OggS` выбирает Vorbis раньше проверки MP3.
Сохранение путей позволяет обойти SMPEG без правки таблиц клиента или его EXE.
Не меняй расширения вручную. Композиции остаются теми же; меняется кодирование звука,
поэтому новые файлы не побитово идентичны оригинальным MP3. Оригиналы сохранены отдельно.
Параметры: Vorbis quality 6, стерео, 44100 Гц, без нормализации громкости.

## Основание и границы проверки

В предоставленном дампе зависшего клиента:

- главный поток ожидает в `SDL_LockAudio` → `SDL_mutexP` → бесконечное ожидание mutex;
- блокировку удерживает поток смены музыки, находящийся в `Mix_PlayMusic`/SMPEG
  и ожидающий поток декодера;
- поток аудиовывода также ожидает эту блокировку; декодер ожидает семафор.

Ранее предложенное отключение многопоточной загрузки ресурсов не помогло. Дамп
показывает конкретную блокировку в звуковом тракте в момент снятия снимка; один дамп
не доказывает, что все наблюдаемые зависания имеют только эту причину.

Код Game.exe в дампе побайтово совпал с ранее предоставленным Game.exe. Для загруженного
SDL_mixer.dll выполнена его настоящая функция выбора декодера в эмуляторе:
одинаковое имя `music/unchanged-name.mp3` с MP3-заголовком выбирает SMPEG, а с `OggS` —
Vorbis. Файловый ввод/вывод и CRT-помощники подставлены; эмуляция останавливается на
входе в декодер. **Это проверка выбора декодера, не тест воспроизведения Windows.**

Пройдены 9 автоматических проверок с настоящим FFmpeg на синтетических записях:
преобразование, полный декод нового файла, длительность, пути с кириллицей,
неизменность WAV/EXE/CFG, повторный запуск, прерывание и точное восстановление.
Проверки выполнены на Linux. Вся музыка пользователя пока не обработана и в игре
этой версией не прослушана. Программа проверяет длительность и полностью декодирует
каждую композицию на твоём ПК до замены её оригинала.

Сам дамп, пути пользователя, данные сеанса и музыкальные файлы в выпуск не включены
и на GitHub не публикуются. Программа ничего не загружает с твоего ПК в интернет.
