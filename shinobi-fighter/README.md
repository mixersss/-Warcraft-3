# SHINOBI CLASH · Путь ниндзя — Alpha02

Самостоятельный 2D-файтинг в браузере: 16 бойцов, 64 именованные техники, разные обычные атаки и13 присланных пользователем полных музыкальных треков. Не требует Warcraft. Рисовка векторная: крупные фигурки с разными причёсками, одеждой, оружием и анимациями; фон — тренировочная арена около Конохи. Модели Warcraft не используются.

[Что изменилось в Alpha02](Release-02.md) · [Привязки голосов](VOICES.md). Добавлены исходные голоса, отдельные A-удар рукой и D-удар ногой, приседание на ↓, реакции попадания и более понятные эффекты64техник.

## Запуск

[Скачать ZIP](../releases/shinobi-fighter/Shinobi-Clash-Alpha02.zip), распаковать и открыть `Shinobi-Clash-Alpha02.html` в Chrome/Edge. Внутри одного файла находится игра и музыка, сервер не нужен. В управляемом Chromium рабочей среды переходы по file:// запрещены; автономная сборка проверена загрузкой содержимого HTML с блокировкой HTTP-запросов, а не обходом этой политики.

Публичный адрес после успешной публикации GitHub Pages: **https://mixersss.github.io/-Warcraft-3/fighter/**. Доступность адреса из среды пока не подтверждена. Workflow `.github/workflows/shinobi-web.yml` публикует стратегию в корне сайта, а файтинг в `/fighter/`, пытаясь включить Pages автоматически. Если появится404/ошибка configure-pages, выбери в репозитории Settings → Pages → Source → GitHub Actions и повторно запусти workflow.

Для разработки: `python3 -m http.server 8080 --directory shinobi-fighter`, открыть localhost:8080.

## Бойцы и навыки

Наруто, Саске, Сакура, Рок Ли, Нейджи, Хината, Тен-Тен, Шикамару, Киба, Гаара, Канкуро, Темари, Какаши, Итачи, Джирайя, Орочимару. [Таблица всех техник](HEROES.md).

У каждого собственные характеристики, дальность и ритм обычных ударов, три техники за чакру и одна ульта. У Хьюга обычные ладони расходуют чакру противника; Тен-Тен, Темари и Итачи используют летящие снаряды. Ли и Киба быстрее, Сакура сильнее в ближнем бою, Гаара и Джирайя выносливее. Основные механики: рывковые атаки, снаряды, ловушки, серия ударов, призывы, лечение, временное усиление, контролирующие тени и атаки по области.

Названия и стили основаны на нашей Naruto RPG и мире Наруто. Для формата файтинга навыки адаптированы: это не точное копирование всех пяти Warcraft-способностей, исходных триггеров, их чисел. Обычные удары тоже адаптированы под дуэль.

## Управление

- Стрелки ←/→ — двигаться, ↓ — присесть; Пробел — прыгать; Shift — рывок с короткой неуязвимостью.
- A — удар рукой, D — удар ногой (J/K дублируют). U — сильный удар, I — фирменная обычная атака героя; L — удерживать блок. Блок спереди уменьшает урон на80%. В приседе можно пропускать высокие атаки; низкие и большие техники попадают.
- Q/W/E — техники за чакру с разными перезарядками. Чакра восстанавливается со временем.
- R — ульта при100% золотой шкалы; она растёт при нанесении и получении урона.
- P/Esc — пауза. Кнопки техник доступны также мышью; на узком экране есть сенсорные кнопки движения/прыжка/атаки/защиты.

Перед боем можно выбрать соперника и одну из трёх сложностей ИИ. Матч до двух побед, каждый раунд99секунд; при тайм-ауте сравниваются доли оставшегося здоровья. Клоны, питомцы и ловушки имеют конечное время жизни; оглушение не превышает1,8секунды. Музыка перемешивается без повторов внутри13трекового круга и на его стыке; воспроизведение начинается после нажатия «Начать бой»/«Музыка». Есть отдельные выключатели голосов из карты и синтезированных боевых звуков.59исходныхголосов связаны с64навыками, музыка приглушается на время речи. Для новых техник без собственной записи используются реплики того же бойца.

Использует подстановку локальных ресурсов без слушающего сервера; процесс Chromium в рабочей среде требует разрешения.

`node shinobi-fighter/test/voices.test.js` — три проверки переиспользуемых голосовых каналов, очередности, отмены и отключения.

`python3 shinobi-fighter/build.py` — автономные HTML/ZIP в releases/shinobi-fighter, музыка встроена целиком. Не требует npm-библиотек для самой игры.

Первая версия: одиночные дуэли против ИИ, одна арена. Пока нет сетевой игры, сюжетной кампании, профессиональных покадровых спрайтов или полной анимации каждого оригинального приёма. Баланс16бойцов требует игровых отзывов; схожие семейства техник используют общие компоненты движка с разными параметрами и оформлением. Долгие сессии, все браузеры и физические телефоны не проверены. Существующая стратегия и Warcraft-карты сохранены.
