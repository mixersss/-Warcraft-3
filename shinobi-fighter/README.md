# SHINOBI CLASH · Путь ниндзя — Alpha03

Самостоятельный2Dфайтинг:16персонажей,64техники, голоса из нашей Naruto-карты и13твоихмузыкальныхтреков. Не требует Warcraft. [Изменения Alpha03](Release-03.md) · [Все техники](HEROES.md) · [Исходные голоса](VOICES.md).

## Что изменилось

Все приёмы работают **по КД, без маны и накопления ульты**. Клоны живут **6секунд**, всех клонов и питомцев можно убить. Проверены урон атакующих техник, лечение и реальные усиления. Плавнее движение и отдача, улучшено соответствие эффекта зоне попадания. Голоса снижены до65%. Сделан первый проход по костюмам всех16бойцов по твоим изображениям; графика пока остаётся векторной, без готовых покадровых спрайтов.

## Запуск

[Скачать ZIP](../releases/shinobi-fighter/Shinobi-Clash-Alpha03.zip), распаковать и открыть `Shinobi-Clash-Alpha03.html` в Chrome/Edge. Внутри вся игра, музыка и голоса; сервер не нужен. Автономная сборка в управляемом Chromium проверяется загрузкой её содержимого с заблокированнымиHTTPзапросами: прямой переход file:// запрещён политикой браузера и не обходится.

Адрес после успешного размещения GitHub Pages: **https://mixersss.github.io/-Warcraft-3/fighter/**. Доступность из среды пока не подтверждена. Если там404/ошибка публикации, выбери Settings → Pages → Source → GitHub Actions и запусти workflow повторно. Стратегия остаётся в корне сайта.

Разработка: `python3 -m http.server 8080 --directory shinobi-fighter`, затем localhost:8080.

## Управление

- **A — рука, D — нога**, J/K дублируют их. A/D не перемещают героя.
- **←/→ — идти, ↓ — присесть, Пробел — прыгнуть, Shift — рывок.** Высокие атаки можно пропустить над головой, низкие и большие техники попадают.
- **Q/W/E/R — техники по перезарядке.** R — ульта с отдельнымКД28–40с. Ресурса для неё нет. При наведении/в справке виден смысл управления.
- U — сильный удар, I — фирменная обычная атака героя (в том числе дальнее оружие), L — держать блок. P/Esc — пауза.

Матч против ИИ до двух побед, раунд99секунд. Есть выбор противника и три сложности. Питомцы имеют HP и ограниченное время; повтор той же техникой заменяет прежний призыв. В меню отдельные переключатели музыки, голосов и эффектов. Музыка перемешивается без повторов внутри круга и на его стыке.

## Проверки

`node shinobi-fighter/test/combat.test.js` —20проверок симуляции, включая все64приёма, реальные попадания/усиления, КД, убиваемых питомцев и6секундклонам.

`node shinobi-fighter/test/voices.test.js` — три проверки каналов речи, отмены, двух частей и отключения.

`node shinobi-fighter/test/browser-smoke.cjs` — настоящий Chromium, реальные клавиши/голоса/костюмы/эффекты, результат/реванш и автономныйHTML. Использует подстановку файлов без слушающего сервера; процесс Chromium в среде требует разрешения.

`python3 shinobi-fighter/build.py` собирает автономныеHTML/ZIP. `python3 shinobi-fighter/verify-alpha03.py` независимо проверяет встроенные13треков и59реплик на побайтное совпадение с Alpha02 и исходниками.

Баланс, художественные детали и анимация продолжают дорабатываться. Предыдущие Alpha01/02, отдельная стратегия и Warcraft-карты сохранены.
