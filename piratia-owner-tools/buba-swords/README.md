# Fix03: выдача двух мечей buba на классическом GameServer

На скриншоте владельца подтверждено: GetPlayerByName отсутствует. Версии01/02
не подходят для прямого поиска персонажа. Fix03 получает персонажа из штатного
обработчика диалога NPC MsgProc, поэтому поиск по имени через эту функцию не нужен.
Уровень35 и профессия уже назначены владельцем: Fix03 их не меняет.

1. Распакуй новый архив в новую папку.
2. Запусти **Install-Buba-Swords.cmd**, укажи папку GameServer или resource.
   Старые скрипты01/02 обновляются только при совпадении известных контрольных сумм,
   создаётся резервная копия. Неизвестные изменения не перезаписываются.
   Файл состояния предыдущей выдачи сохраняется. NPC/SDK и таблицы БД не редактируются.
3. Войди за **buba** с пока ещё включёнными правами ГМ. Освободи четыре ячейки сумки.
   Закрой все открытые диалоги NPC.
4. Введи целиком в игровой чат:

   ```text
   &lua dofile(GetResPath("script/BubaNPC.lua"))
   ```

   Должно появиться **BubaNPC READY**. Если вместо этого SETUP ERROR, пришли полный текст.
5. **Поговори с любым НПС за buba.** В обычном обработчике диалога будет передан
   настоящий персонаж и выданы две новые вещи. Ожидаемое сообщение — **received 2...**.
   Для остальных персонажей и ботов обычные диалоги продолжают работать.
6. После получения вещей выйди с аккаунта, выполни **Disable-GM-buba.sql** в SSMS,
   затем войди снова обычным игроком. Если ГМ уже выключен, можно временно включить
   его через приложенный Enable-GM-buba.sql, как в предыдущей инструкции.

Активация работает до перезапуска GameServer или перезагрузки NPC SDK. Она не
сохраняется в NpcSdk.lua. Повторная активация не даёт второй набор благодаря
**owner-buba-swords-01.state** в resource. Не удаляй этот файл для повторной попытки.
При ошибке часть новых вещей могла уже создаться; состояние pending требует проверки.

Каждый меч: основа Assassin Sword1397,35уровень, один меч в одну руку;
аппарель Sword of Crimson Thunder5002, усиление15; три разных гема9уровня:
Ярость, Глаз Чёрного дракона, Огненный самоцвет. Итого +27, +45силы и +486к обеим
границам атаки до прочих множителей. Прежняя экипировка не изменяется. Удаляются
только временные основы, созданные этим запуском для штатного слияния.

Если уже было pending/done, новый скрипт не удаляет записи и не выдаёт дубликаты.
Ошибки в процессе выдачи теперь выводятся персонажу как **BubaNPC ERROR** и в окно
GameServer. Fix03 проверен локально с отсутствующей GetPlayerByName, пустыми
ячейками, возвращающими0, и сумкой24ячейки. Реальная выдача в твоём GameServer
пока не подтверждена; если появится ошибка, пришли её текст, не запускай выдачу вслепую.
