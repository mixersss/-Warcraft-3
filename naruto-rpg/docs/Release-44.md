# Shinobi Story Alpha44

[Скачать карту](../../releases/shinobi-new/Shinobi_Story_Alpha_44.w3x). Начать новую игру Warcraft III1.26.

Вторжение: устранена возможность выдачи героям награды за добивания обычной NPC-армией через новую явную проверку убийцы. Изменён состав волн: **3 → 3 → 4 → 3 → 3 → 4**, отдельно для каждого из восьми направлений. Периоды, задержки, маршруты, начальные защитники и появление боссов не менялись; четвёртая безопасная позиция формации сохранена.

| Убийца NPC во время активного вторжения | Награда герою |
|---|---|
| Обычный ниндзя Песка, Звука, Листа, АНБУ, медик или другой самостоятельный NPC | Нет |
| Настоящий герой игрока или бота | Да, если цель враждебна |
| Его клон, призванное существо или отслеживаемый питомец | Да, владельцу |
| Вспомогательный юнит его техники: дым, ветер, взрывные бомбы и т.п. | Да, владельцу |
| Союзное добивание, смерть без убийцы, убийство иллюзии | Нет |

Для жертв NPC-владельцев13/15 во время этапа12 отключена автоматическая выдача движком. Один постоянный обработчик смерти проверяет реального `GetKillingUnit`, владельца, связь с героем/питомцем и враждебность, затем выдаёт единственную награду. Обычный ниндзя не получает право награждать героя даже при ошибочном назначении ему владельца игрока. Для жертв, принадлежащих игрокам0–11, прежние нативные правила сохранены. После этапа все16 прежних флагов выдачи награды восстанавливаются существующим CampaignClear.

Размер награды не урезан. Для обычных ниндзя сохранено **20 + 6 отдельных бросков d3 = 26–38, среднее32**; для остальных NPC берутся их реальные поля объекта с унаследованными значениями из зафиксированной Classic-таблицы. Сохранено распределение суммы костей, а не равномерный случайный выбор между минимумом и максимумом. Все эффективные значения для каждого объекта карты проверяются независимо по бинарному W3U. Жёлтая надпись показывается получателю, уничтожается движком по времени жизни; новых таймеров и изменений цен/покупок нет.

Исходная причина наблюдавшейся выдачи золота обычными ниндзя в движке1.26 не подтверждена: в Alpha43 не найдено прямого скриптового перевода героям NPC-дохода. Поэтому новый выпуск не объявляет найденным конкретный старый триггер: он заменяет автоматическую выдачу за NPC контролируемым правилом и добавляет диагностику.

**`-goldcheck`** — команда первого игрока-человека во время вторжения. Показывает для12героев число оплаченных добиваний NPC, полученное за них золото с начала текущего вторжения и текущий запас. Текущий запас также отражает предыдущие этапы, покупки и прочие существующие источники. Команда только читает данные. Для быстрого теста доступны прежние `-village fast` и команды восстановления Саске.

Проверки пройдены: сборка, строгий Classic pjass, два независимых MPQ-чтения и392SHA, полный test-skills, test-commands, verify-invasion44 и статические маршруты verify-invasion20. Native-моки запускают реальный обработчик смерти:100убийств NPC-армией не дают героям золота; все три героя Песка, герой Листа, питомец, клон и помощник техники получают корректную сумму; проверены союзные/нулевые убийцы, иллюзии, переход/окончание этапа, крайние26/38 и отсутствие повторной регистрации. Проверено6волн каждого направления, исходные позиции, команды диагностики и ограничения доступа.

Все объекты, навыки, цены, музыка, импортированные ресурсы, ландшафт, слоты и остальной сюжет побайтно совпадают с Alpha43. Новые скриптовые данные загружаются небольшими отдельными функциями, без дополнительных таймеров. Проверка не заменяет запуск Warcraft: нужно подтвердить реальные начисления, плавающие надписи и движение волн в1.26. Footman не изменён.
