# Сравнение запрошенных навыков с оригиналами 3.5 и 4.2i

Проверены бинарные записи способностей обеих присланных карт и восстановленный JASS. Это сравнение механик; сами семь навыков в Alpha39 не заменены целиком. Чидори/Расенган и превращения исправлены отдельно. Значения повреждённых/неиспользуемых рангов оригинала не принимаются за работающие ранги: например, A027 имеет один ранг, хотя содержит остаточные записи рангов 2–4.

Текущие параметры: [playable-skills.json](../src/playable-skills.json).

Повторно перенести спящие триггеры оригинала целиком нельзя считать безопасной заменой: в них общие глобальные переменные, управление конкретными номерами игроков и очистка чужих объектов. Для точного воспроизведения нужны отдельные состояния каждого применения и отдельные проверки ИИ. Здесь оригинальные значения приведены как обнаруженные факты, а не как уже внесённые изменения.
