# Four Fronts Frenzy — 0.2.0-alpha

Самостоятельная карта в духе **Footman Frenzy** для **Warcraft III: The Frozen Throne Classic 1.26–1.28**. Четыре команды по три игрока; подкрепления появляются постоянно, золото позволяет развивать армию и героя. Есть собственный сценарный ИИ.

**Статус:** пользователь подтвердил запуск и работу ботов версии 0.1.1 в Warcraft III 1.26. Версия 0.2.0 добавляет 4 расы армии, 24 героя, случайный выбор для ботов, видимую кнопку улучшений и ограждения с одним проходом. Форматы, JASS, меню, экономика и сетка проходимости проверены автоматически. Новые меню, способности и стены в самой игре ещё не проверены: Warcraft III в облачной среде нет.

## Как запустить

1. Возьми `releases/FourFrontsFrenzy-0.2.0-alpha.w3x` (либо новую сборку из `build/`) и скопируй в папку `Maps\Download`, которую использует твоя установка Warcraft III. Убери старую версию из этой папки, чтобы не выбрать её случайно.
2. Открой **Одиночная игра → Своя игра** и выбери карту. Для первого теста поставь **Компьютер** на остальные 11 мест. Сложность компьютера пока не меняет наш ИИ.
3. Команды заданы местами: 1–3, 4–6, 7–9, 10–12. Все места поддерживают людей. Пустые места также должны подхватываться сценарным ИИ; этот сценарий отдельно требует проверки в игре.
4. В начале автоматически откроется выбор расы армии, затем категории героев и героя. Доступны 16 расовых и 8 нейтральных героев. До начала боя выбор можно повторить через `-race` и `-hero`. Если ничего не выбрать, останутся Альянс и Паладин. Подготовка длится 60 секунд; герои в это время стоят на месте. После покупки характеристик смена героя закрывается.
5. Выдели казарму или героя и нажми кнопку **Меню армии [U]** для улучшения армии. Работает и команда `-shop`. Армия по умолчанию получает автоматические приказы; `-auto` переключает ручное управление.

Основные меню выбора и улучшений на русском. Справка также доступна по **F9**.

## Правила первой версии

| Механика | Значение |
| --- | --- |
| Формат | 12 мест, 4 команды по 3 |
| Старт | 500 золота, 60 секунд подготовки |
| Подкрепления | 2 бойца ближнего боя + 1 стрелок выбранной расы каждые 8 секунд |
| Лимит | 48 обычных бойцов на игрока; призванные существа отдельно |
| Расы армии | Альянс, Орда, Нежить, Ночные эльфы; у каждой 5 ступеней |
| Атака | 10 улучшений по +3 урона |
| Броня | 10 улучшений по +1 |
| Спавн | Интервал можно сократить до 4 секунд |
| Экономика | +4 золота в секунду после подготовки; награды за убийства |
| Герои | 24 стандартных героя Warcraft III 1.26, в том числе 8 нейтральных |
| Развитие героя | Опыт и уровни; покупка +3 ко всем характеристикам, до 10 раз |
| Возрождение | Бесплатно через 15 + 3 × уровень секунд, пока жива своя база |
| База | 6000 здоровья и отдельная защитная башня |
| Победа | Уничтожить все три базы каждой вражеской команды |

Новая ступень меняет **следующие** волны. Улучшения атаки и брони распространяются и на существующих солдат. Своя уничтоженная база больше не выпускает войска, не даёт доход и не воскрешает героя; оставшимися бойцами можно помогать союзникам. Команда выбывает после потери всех трёх баз.

Арена симметрична при повороте на 90 градусов. В каждом углу три союзные базы окружены неразрушаемой каменной стеной с единственным проходом шириной около 960 единиц к центру. Обычные наземные войска проходят через эти ворота; стандартные полёты и телепортация героев сохраняются. Новые волны идут через центр, затем к выбранной вражеской базе. При угрозе союзным базам автоматические приказы переключаются на защиту.

Выбор расы не ограничивает выбор героя. Например, армией Нежити может командовать герой Альянса. Ступень развития меняет состав будущих волн; цены, уровни исследований и лимиты общие. Расы имеют свои модели бойцов, стрелков и названия ступеней.

## Боты

Боты работают через обычные JASS-триггеры; стандартный melee AI не запускается. Они:

- случайно выбирают любую из 4 рас и любого из всех 24 героев при запуске матча; повторы героев разрешены;
- получают тот же стартовый капитал, доход и награды, что и люди;
- покупают улучшения через ту же функцию и по тем же ценам, копят на следующие ступени;
- выбирают общую цель команды и возвращают войска для защиты баз;
- управляют героем, распределяют очки способностей, применяют поддерживаемые боевые умения;
- отводят раненого героя на лечение и возвращаются в бой после возрождения;
- подхватывают управление после выхода человека.

Пока предусмотрен один уровень ИИ. У каждого из 24 героев есть список навыков и поддерживаемых боевых приказов. Учитываются лечение живых/нежити, призывы, пассивные умения, улучшенные навыки Изобретателя, отступление и пауза при поддержании заклинаний. ИИ использует часть активных умений каждого героя: например, Архимаг призывает элементалей, но не применяет Blizzard и Mass Teleport. Микроконтроль и сила разных героев требуют игровых тестов. Магазина предметов в этой альфе нет: развитие героя идёт через уровни и характеристики.

## Команды

| Команда | Действие |
| --- | --- |
| `-shop` | Меню с текущими ценами |
| `-race` | Выбор расы армии до начала боя |
| `-hero` | Выбор одного из 24 героев до начала боя |
| `-race random`, `-hero random` | Случайная раса или герой |
| `-attack`, `-armor`, `-tier`, `-spawn` | Купить соответствующее улучшение армии |
| `-power` | Купить +3 ко всем характеристикам героя |
| `-heal` | Полностью восстановить героя за 150 золота рядом со своей базой |
| `-auto` | Включить/выключить автоматические приказы армии; герой остаётся ручным |
| `-go` | Отправить войска к общей цели |
| `-status` | Показать ступень, улучшения, спавн и размер армии |
| `-hero paladin`, `-hero king`, `-hero mage`, и другие псевдонимы из `map/heroes.json` | Прямой выбор героя |
| `-race human`, `-race orc`, `-race undead`, `-race elf` | Прямой выбор расы |
| `-help` | Краткая справка |

## Сборка и проверки

Для сборки достаточно **Python 3.10+**, без внешних Python-пакетов:

```sh
python3 tools/build.py
```

Для автоматических проверок нужен Node.js и зависимости из lockfile:

```sh
npm ci --cache /tmp/warcraft-npm-cache
npm test
```

Проверки читают получившийся MPQ независимым парсером `mdx-m3-viewer`, проверяют 13 бинарных форматов и 40 вариантов бойцов. Тесты исполняют **функции собранного JASS**, переведённые в Lua, с подменой нативного API: лобби, покупки, меню, 4 расы × 5 ступеней, выбор/случайная выдача всех 24 героев, обучение навыкам, боевые приказы, спавн, убийства, выбывание и возрождение. Проверка WPM обходом клеток доказывает доступность всех баз и отсутствие второго наземного выхода из каждого ограждения. Это не симуляция движка Warcraft III и не проверка сетевой синхронизации.

Дополнительная проверка синтаксиса/типов — `pjass common.j Blizzard.j +shadow +checkglobalsinit +checkstringlength +nomodulooperator build/map/war3map.j` с объявлениями старого API из вашей установки Warcraft III. Флаги после библиотек применяют строгие проверки к карте, не к игровым библиотекам. В облачной среде использованы старые объявления из `lep/jassdoc` (tag `0.1.0`) и `Blizzard.j` 1.24.4 из `sumneko/w3x2lni`; проверка прошла. Чужие игровые библиотеки в карту не включаются.

В `0.1.1-alpha` исправлено имя параметра `force`, конфликтовавшее со встроенным типом JASS и мешавшее отображению лобби. После этого пользователь подтвердил, что карта запускается и боты играют. Проверки продолжают отклонять такие имена и отдельно проверяют настройку всех 12 мест.

Исходники: `map/war3map.j` — сценарий, `map/balance.json` — параметры, `map/races.json` и `map/heroes.json` — каталоги армий и героев, `tools/build.py` — генератор ландшафта, объектов, стен и MPQ. Форматы: W3I 25, W3E 11, объекты 2, MPQ 0. API `Blz*`, Lua в игре, внешние модели и сторонние игровые плагины не используются. Современный World Editor может повысить версию формата; пересохранение в редакторе также может заменить сгенерированный JASS. Для доработок используй исходники и генератор.

## Первый игровой тест

- Карта видна в списке и загружается в Classic; все 12 баз и героев созданы.
- В начале отображается выбор расы, затем героев; все 24 героя доступны. Смена закрывается в 01:00.
- В 01:00 герои получают управление и появляются первые 3 бойца выбранной расы; затем по 3 каждые 8 секунд.
- Кнопка Меню армии [U] на казарме и герое открывает меню; атака/броня меняют характеристики существующих войск, ступень — следующие волны.
- Базы трёх союзников окружены стенами с одним проходом. Бойцы выходят через него и могут вернуться для защиты.
- Компьютеры развивают армии, дерутся, защищаются и возвращают героев после гибели.
- Пехота и кавалерия проходят мимо баз и башен; нет заторов на точках появления.
- Потеря одной базы не выводит всю команду; потеря третьей выводит её; последняя команда получает победу.
- В LAN-матче два человека могут занять любые свободные места; покупки и диалоги не вызывают рассинхронизацию.

## Ориентир и источники

Из Footman Frenzy взят базовый игровой цикл: автоматическая армия, золото за бои, усиление армии, герой и уничтожение баз. Здесь собственные числа, ступени и ИИ; точная копия конкретной версии оригинала не заявляется. Прямое обращение к Hive Workshop из облачной среды вернуло HTTP 403, поэтому параметры оригинальной карты по этому источнику не сверялись.

Технические форматы сверены с [WC3MapSpecification](https://github.com/ChiefOfGxBxL/WC3MapSpecification), [mdx-m3-viewer](https://github.com/flowtsohg/mdx-m3-viewer) и метаданными из [w3x2lni](https://github.com/sumneko/w3x2lni). Проверка JASS: [pjass](https://github.com/lep/pjass).
