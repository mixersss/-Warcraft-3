# Four Fronts Frenzy — 0.1.1-alpha

Самостоятельная карта в духе **Footman Frenzy** для **Warcraft III: The Frozen Throne Classic 1.26–1.28**. Четыре команды по три игрока; подкрепления появляются постоянно, золото позволяет развивать армию и героя. Есть собственный сценарный ИИ.

**Статус:** файл `.w3x` собран; структура карты, JASS и логика экономики проверены. Запуск в настоящем Warcraft III, сетевой матч, проходимость арены и баланс ещё не проверены: игры и World Editor в облачной среде нет. Это кандидат для первого пробного матча, а не законченный релиз.

## Как запустить

1. Возьми `releases/FourFrontsFrenzy-0.1.1-alpha.w3x` (либо новую сборку из `build/`) и скопируй в папку `Maps\Download`, которую использует твоя установка Warcraft III. Предыдущую `0.1.0-alpha` удали из этой папки, чтобы не выбрать её случайно.
2. Открой **Одиночная игра → Своя игра** и выбери карту. Для первого теста поставь **Компьютер** на остальные 11 мест. Сложность компьютера пока не меняет наш ИИ.
3. Команды заданы местами: 1–3, 4–6, 7–9, 10–12. Все места поддерживают людей. Пустые места также должны подхватываться сценарным ИИ; этот сценарий отдельно требует проверки в игре.
4. В первые 30 секунд выбери героя командой `-hero paladin`, `-hero king` или `-hero mage`. Изначально герой уже выдан. После покупки характеристик смена героя закрывается.
5. Напиши `-shop`, купи улучшения и веди героя в бой. Армия по умолчанию получает автоматические приказы; `-auto` переключает ручное управление.

Интерфейс внутри карты пока на английском. Правила и команды также доступны по **F9**.

## Правила первой версии

| Механика | Значение |
| --- | --- |
| Формат | 12 мест, 4 команды по 3 |
| Старт | 500 золота, 30 секунд подготовки |
| Подкрепления | 2 бойца ближнего боя + 1 стрелок каждые 8 секунд |
| Лимит | 48 обычных бойцов на игрока; призванные существа отдельно |
| Ступени армии | Пехота → Ветераны → Грунты → Рыцари → Таурены |
| Атака | 10 улучшений по +3 урона |
| Броня | 10 улучшений по +1 |
| Спавн | Интервал можно сократить до 4 секунд |
| Экономика | +4 золота в секунду после подготовки; награды за убийства |
| Герои | Паладин, Горный король, Архимаг |
| Развитие героя | Опыт и уровни; покупка +3 ко всем характеристикам, до 10 раз |
| Возрождение | Бесплатно через 15 + 3 × уровень секунд, пока жива своя база |
| База | 6000 здоровья и отдельная защитная башня |
| Победа | Уничтожить все три базы каждой вражеской команды |

Новая ступень меняет **следующие** волны. Улучшения атаки и брони распространяются и на существующих солдат. Своя уничтоженная база больше не выпускает войска, не даёт доход и не воскрешает героя; оставшимися бойцами можно помогать союзникам. Команда выбывает после потери всех трёх баз.

Арена симметрична при повороте на 90 градусов. Новые волны сначала идут через центр, затем к выбранной вражеской базе. При угрозе союзным базам автоматические приказы переключаются на защиту.

## Боты

Боты работают через обычные JASS-триггеры; стандартный melee AI не запускается. Они:

- получают тот же стартовый капитал, доход и награды, что и люди;
- покупают улучшения через ту же функцию и по тем же ценам, копят на следующие ступени;
- выбирают общую цель команды и возвращают войска для защиты баз;
- управляют героем, распределяют очки способностей, применяют поддерживаемые боевые умения;
- отводят раненого героя на лечение и возвращаются в бой после возрождения;
- подхватывают управление после выхода человека.

Пока предусмотрен один уровень ИИ. Микроконтроль, применение всех способностей, поведение под фокусом и сила в сравнении с человеком требуют игровых тестов. ИИ Архимага призывает элементалей, но пока не использует Blizzard и Mass Teleport; так он избегает обстрела союзной пехоты. Магазина предметов в этой альфе нет: развитие героя идёт через уровни и характеристики.

## Команды

| Команда | Действие |
| --- | --- |
| `-shop` | Меню с текущими ценами |
| `-attack`, `-armor`, `-tier`, `-spawn` | Купить соответствующее улучшение армии |
| `-power` | Купить +3 ко всем характеристикам героя |
| `-heal` | Полностью восстановить героя за 150 золота рядом со своей базой |
| `-auto` | Включить/выключить автоматические приказы армии; герой остаётся ручным |
| `-go` | Отправить войска к общей цели |
| `-status` | Показать ступень, улучшения, спавн и размер армии |
| `-hero paladin`, `-hero king`, `-hero mage` | Выбрать героя до начала боя и покупки характеристик |
| `-help` | Краткая справка |

## Сборка и проверки

Для сборки достаточно **Python 3.10+**, без внешних Python-пакетов:

```sh
python3 tools/build.py
```

Для автоматических проверок нужен Node.js и зависимости из lockfile:

```sh
npm ci --cache /tmp/warcraft-npm-cache
npm test
```

Проверки читают получившийся MPQ независимым парсером `mdx-m3-viewer`, проверяют форматы, команды, путь и ID объектов. Сценарии экономики, спавна, убийств, выбывания и возрождения исполняют **функции собранного JASS**, переведённые в Lua, с подменой нативного API. Это не симуляция движка Warcraft III и не проверка сетевой синхронизации.

Дополнительная проверка синтаксиса/типов — `pjass common.j Blizzard.j +shadow +checkglobalsinit +checkstringlength +nomodulooperator build/map/war3map.j` с объявлениями старого API из вашей установки Warcraft III. Флаги после библиотек применяют строгие проверки к карте, не к игровым библиотекам. В облачной среде использованы старые объявления из `lep/jassdoc` (tag `0.1.0`) и `Blizzard.j` 1.24.4 из `sumneko/w3x2lni`; проверка прошла. Чужие игровые библиотеки в карту не включаются.

В `0.1.1-alpha` исправлено имя параметра `force`, конфликтовавшее со встроенным типом JASS. В `0.1.0-alpha` игрок сообщил о пустом списке участников в Warcraft III 1.26; усиленная проверка `pjass +shadow` выявила этот конфликт. Проверки теперь отклоняют такие имена и исполняют `config()` отдельно от игровой инициализации, сверяя 12 доступных мест и четыре команды по три с метаданными карты. Отображение исправленной версии в настоящем лобби пока не подтверждено.

Исходники: `map/war3map.j` — сценарий, `map/balance.json` — параметры, `tools/build.py` — генератор ландшафта, объектов и MPQ. Форматы: W3I 25, W3E 11, объекты 2, MPQ 0. API `Blz*`, Lua в игре, внешние модели и сторонние игровые плагины не используются. Современный World Editor может повысить версию формата и нарушить совместимость с 1.26; исходную сборку нужно сохранять.

## Первый игровой тест

- Карта видна в списке и загружается в Classic; все 12 баз и героев созданы.
- В 00:30 появляются первые 3 бойца; затем по 3 каждые 8 секунд.
- `-shop` списывает правильную цену; атака/броня меняют характеристики существующих войск, ступень — следующие волны.
- Компьютеры развивают армии, дерутся, защищаются и возвращают героев после гибели.
- Пехота и кавалерия проходят мимо баз и башен; нет заторов на точках появления.
- Потеря одной базы не выводит всю команду; потеря третьей выводит её; последняя команда получает победу.
- В LAN-матче два человека могут занять любые свободные места; покупки и диалоги не вызывают рассинхронизацию.

## Ориентир и источники

Из Footman Frenzy взят базовый игровой цикл: автоматическая армия, золото за бои, усиление армии, герой и уничтожение баз. Здесь собственные числа, ступени и ИИ; точная копия конкретной версии оригинала не заявляется. Прямое обращение к Hive Workshop из облачной среды вернуло HTTP 403, поэтому параметры оригинальной карты по этому источнику не сверялись.

Технические форматы сверены с [WC3MapSpecification](https://github.com/ChiefOfGxBxL/WC3MapSpecification), [mdx-m3-viewer](https://github.com/flowtsohg/mdx-m3-viewer) и метаданными из [w3x2lni](https://github.com/sumneko/w3x2lni). Проверка JASS: [pjass](https://github.com/lep/pjass).
