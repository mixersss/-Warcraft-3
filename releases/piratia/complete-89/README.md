# Alpha89. Слабые мобы на маршруте прокачки

Слабый моб ниже текущей границы прокачки больше не перехватывает
маршрут или выбранную цель одним незначительным ударом. Самооборона
от такого моба разрешена при 75% здоровья или ниже либо при потере
10% максимального здоровья за последние три секунды. При критическом
здоровье сохраняется штатный отход. Заработок Пачкули на обязательные
покупки и квестовые цели по-прежнему могут использовать слабых мобов.

В отчёте поле last_monster_attack содержит вид, уровень цели и
границу прокачки при отправке атаки. Поле weak_attack_reasons
считает отправленные атаки по причинам. Факт получения опыта
по-прежнему подтверждается серверной записью.

Для обновления остановите ботов, распакуйте Alpha89 Complete в новую
папку, скопируйте в неё всю рабочую папку data и запустите Start-World.cmd.
Установленная серверная ревизия 60 подходит. Проверки выполнены вне игры.
