# Alpha68. Пеший маршрут к лагерю сохраняет приоритет

Между двумя снимками Alpha66 один лучник за 184 секунды отправил
23 запроса движения, подтвердился новый переход, а позиция сменилась
на окрестность торговца феями в Аргенте. Атаки и опыт не изменились.
Режим сменился с прокачки на торговлю. Отчёт не содержит точную причину
возврата. В коде воспроизведено, как окно торговли при наличии товаров
могло инициировать городской переход посреди пешего маршрута.

Alpha68 сохраняет приоритет подготовленной пешей охоты до окончания
действующего маршрута. После достижения точки есть до 45 секунд
на поиск боя. Переход к новому подходящему месту и проверки безопасности
остаются доступны. Необязательные городские поездки, магазины и ларьки
уступают этому маршруту. Сохраняются обязательные услуги, помощь при
заполненной сумке, необходимое боевое снабжение и кормление голодной феи.
Начатые подтверждаемые операции завершаются штатно.

В тесте настоящее торговое окно было доступно для бота с билетом,
но при активном пешем маршруте возврат в Аргент не планировался.
Обязательная услуга и возврат после дедлайна оставались доступны.
Поле hunt.hunting_coordinates.camp_route_priority показывает текущий
приоритет пути. Живые атаки и начисление опыта после установки пока
не подтверждены.

## Обновление

Остановите ботов, распакуйте Alpha68 Complete в новую папку, скопируйте
всю папку data из рабочей версии и запустите Start-World.cmd. При
запросе укажите resource действующего сервера. Установленная серверная
ревизия 60 подходит.
