# Alpha66. Время на охоту после прибытия

В снимке Alpha64 у 22 из 85 ботов в радиусе 15 м от магазина фей
есть подтверждённые возвраты собственным городским билетом. Отчёт
не позволяет установить причину каждого возврата. В коде воспроизведён
сценарий, когда сразу после подтверждённого прибытия в место кача
наступает очередь ремесла и запускается новая поездка в Аргент.

В Alpha66 после подтверждённого прибытия на охоту необязательный возврат
из-за ремесла, торговли и покупок откладывается до прогресса персонажа
или максимум на три минуты. Поездки для обязательных услуг, заполненной
сумки без местного торговца и необходимого боевого снабжения доступны.
Уже открытая операция с торговцем завершается. Обычное лечение и кормление
голодной феи сохраняются.

Тест воспроизводит расход собственного билета, настоящее прибытие и
ожидающую задачу ремесла. Отдельно проверены обязательная услуга,
возврат по истечении срока и снятие ограничения после прогресса.
Исправления планировщика из Alpha65 входят в этот комплект.
Живое поведение после установки ещё не подтверждено.

## Обновление

Остановите ботов, распакуйте Alpha66 Complete в новую папку, скопируйте
всю папку data из рабочей версии и запустите Start-World.cmd. При
запросе укажите resource действующего сервера. Установленная серверная
ревизия 60 подходит.
