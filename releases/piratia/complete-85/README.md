# Alpha85. Лагеря по уровню и распределение ботов

Бот получает список моделей из общего справочника, индексированного
по уровням. В комплекте 608 определений мобов, из которых для 470
известны районы появления, включая морские и условные спавны. Есть
232 наземных вида с положительным базовым опытом и обычным источником
появления на карте с навигацией. Неведомые координаты, расписания
событий и места появления конкретных живых мобов не придумываются.
На уровнях 96–100 в поставляемых данных нет подтверждённых наземных
целей в основном диапазоне. Как и на любом уровне, число пригодных
вариантов зависит от конкретной карты, положения и боевых возможностей.

На текущей карте бот выбирает до трёх отдельных участков на доступной
части карты. Точки одного участка в радиусе 25 м не занимают несколько
мест в списке. Занятость участков учитывается между ботами, а при бое
около выбранной точки ближайшая аренда продлевается. Закрытые проходы
и остановки по-прежнему проверяются сеткой и сервером. Для Серебряной
шахты сохраняется самостоятельный подбор участка по этажам.

Для дальнего перемещения сравниваются до трёх сопоставимых вариантов
портала, билета или двери. Для каждого проверяется пригодный лагерь
после высадки, в том числе для всех возможных точек одного билета.
Похожие места высадки на одной карте объединяются. У ботов одного
уровня выбор может различаться. Оплата, права входа и подтверждение
прибытия остаются штатными серверными операциями.

Если доступны подходящие мобы, обычный нижний порог составляет пять
уровней ниже бота. В запасном диапазоне допускаются цели не ниже
девяти уровней разницы. Мобы с известным нулевым опытом исключаются
из обычного выбора лагеря. Самооборона, квесты и добыча денег на
обязательные закупки сохраняют свои прежние условия.

В проверке 12 ботов распределились по трём участкам. Отдельная
проверка отсеивает дублирующуюся и недоступную высадки. В отчётах
hunting_coordinates.camp_choices_cm и hunting_travel.camp_options
показывают рассмотренные варианты. Распределение на живом сервере
пока не измерено.

Для обновления остановите ботов, распакуйте Alpha85 Complete в новую
папку, скопируйте в неё всю текущую папку data и запустите Start-World.cmd.
Подходит установленная ревизия сервера 60.
