# Alpha65. Выход с городского скопления к лагерю

Снимок Alpha64 содержит 397 отчётов. В мир вошли 390 ботов, 220 отправляли
атаки, у 109 итоговое изменение опыта было положительным. В радиусе 15 м
от продавца фей было 85 ботов. У 78 из них не было открытого визита к
торговцу. У 79 сработало хотя бы одно аварийное восстановление. У 59 был
незавершённый поиск пешего маршрута в основном планировщике. Максимальный
уровень без выданного GM 55-го уровня остался 39.

На сохранённой сетке построились все 59 маршрутов из снимка. Медиана
расширений поиска до результата составила 4 364 узла, медиана числа
расширенных узлов в снимке была 508. Повторение выполнено на базовой
геометрии без временных препятствий отдельных ботов.

Раньше аварийное восстановление после минуты без движения могло снять
резервацию лагеря и отменить незавершённый поиск даже при расширении его
фронта. Отдельно подготовка фоновой задачи могла запустить таймер основного
поиска до его первого шага и исчерпать бюджет этого цикла.

- Пока поиск к той же точке продвигается, он защищён от раннего сброса.
  Через 15 секунд без продвижения или по истечении срока маршрута
  обычное восстановление снова доступно. Защита поиска ограничена 300 секундами
  и общим дедлайном цели, смотря что наступит раньше.
- Подтверждённое сервером продвижение к лагерю учитывается при проверке
  отсутствия результата. Для неподвижного персонажа продолжают действовать
  проверки застревания. Незавершённый поиск просроченной цели снимается.
- Фоновые маршруты с резервом делят между собой до 128 узлов за цикл.
  Если основной поиск ещё не начал работать, его CPU-таймер запускается
  при обработке первого узла. Общий предел 512 узлов сохранён.

Тесты воспроизводят сохранение реально расширяющегося поиска после первой
минуты, восстановление после остановки расширения и ограничение нескольких
фоновых задач. Проверка на Windows с живыми мобами, атаками и ростом уровня
остаётся необходимой.

## Обновление Alpha64 → Alpha65

Остановите ботов, распакуйте Alpha65 Complete в новую папку и скопируйте
туда всю папку data из рабочей версии. Запустите Start-World.cmd. Если
будет запрошен путь к resource, укажите папку действующего GameServer.
Установленная серверная ревизия 60 подходит для этой версии.
