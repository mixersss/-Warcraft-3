# Два меча, профессия мечника и35уровень для buba

Индивидуальный инструмент владельца сервера. Ботов и магазины Alpha55 менять не нужно.

Каждый предмет:

- Основа: **Меч ассассина**, ID1397, одноручный,35уровень, базовая совместимость тел1/2.
- Аппарель: **Меч малинового грома**, ID5002; настоящее серверное слияние FusionItem.
- Усиление аппарели: **15**, максимум в присланном can_beuplv_item_main.
- Три гнезда: **Самоцвет Ярости9**, **Глаз Чёрного дракона9**, **Огненный самоцвет9**.
  Суммарная заточка **+27**. Камни дают +45силы и +486к минимальной/максимальной атаке
  на меч до остальных игровых множителей; это не обещание величины урона по противнику.

Установка и выдача:

1. Распакуй комплект. Запусти **Install-Buba-Swords.cmd**, укажи папку GameServer или resource.
   Копируются только новые `resource/script/BubaSwords.lua` и `BubaLevel35.lua`; NPC и SDK не изменяются.
2. Зайди за **buba**. Освободи **четыре обычные ячейки сумки**. Предметы появятся в сумке,
   прежнее снаряжение не заменяется и не надевается автоматически.
3. Войди именно за **buba** с временными правами ГМ. Выполни в чате по очереди,
   каждую команду отдельно, нажимая Enter:

   ```text
   &attr 4,1
   &lua dofile(GetResPath("script/BubaLevel35.lua"))
   &lua dofile(GetResPath("script/BubaSwords.lua"))
   ```

   buba может выполнить команду сам, если у его аккаунта есть права GM на Lua.
   Обычным персонажем эта команда не выполняется. Права инструмент сам не выдаёт.
   В конкретной сборке Lua-команда может быть отключена; неподдерживаемые функции
   проверяются до выдачи. Перезапуск сервера для одного dofile обычно не требуется.
4. Первая команда назначает мечника, вторая добавляет недостающий до35уровня опыт
   через штатный AddExp — очки за повышение выдаёт сервер. Уровень выше35 не понижается,
   повторного начисления нет. Третья команда выдаёт два меча: дождись `received 2...`.
   Очки не распределяются автоматически; умение носить два меча и расовые ограничения
   отдельным обходом не выдаются. Обычный мечник и продвинутая профессия воителя — разные классы.

Если сейчас играешь без ГМ:

1. Выйди персонажем buba из игры.
2. Открой SSMS, нажми «Создать запрос», вставь содержимое **Enable-GM-buba.sql** и выполни F5.
   Запрос найдёт аккаунт по персонажу buba, проверит единственность и обычный статус gm=0,
   затем временно установит gm=99. Права относятся ко всему этому аккаунту.
3. Зайди за buba, выполни три команды выше: профессия, опыт до35, выдача мечей.
4. После получения двух мечей снова выйди из игры. В SSMS выполни **Disable-GM-buba.sql**.
   Зайди снова: статус аккаунта будет обычным, выданные вещи останутся.

Эти SQL-запросы не редактируют инвентарь. Если появляется ошибка проверки,
не убирай WHERE/проверки: сохрани текст ошибки. Автоматического отката GM по таймеру нет,
поэтому заверши четвёртый шаг. SQL проверен по известной схеме из твоих скриншотов;
на твоей работающей базе облачный помощник его не выполнял.

Защита от повторной выдачи: в resource создаётся `owner-buba-swords-01.state`.
Даже после перезапуска повторный запуск блокируется. Если получилось сообщение об ошибке
или `pending`, сначала проверь сумку и серверный лог: часть новых вещей могла уже создаться.
Не удаляй этот файл для слепого повтора. Старые вещи скрипт не редактирует и не удаляет;
после слияния удаляются только два временных меча-основы, созданных текущим запуском.

Проверено на локальной модели Lua API и копировании файла. Выдача в твоём работающем
GameServer пока не проверена; у облачного помощника нет прямого доступа к твоему ПК.
