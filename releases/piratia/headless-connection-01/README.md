# Пиратия: подключение без окна игры — Connection Alpha 01

Это первый этап работы над ботами для твоего личного сервера PKO 1.38.
Программа подключается как обычный игрок: проверяет пароль, выбирает существующего
персонажа и запрашивает вход в мир. После успешного входа стоит 60 секунд и выходит.
**Бой, передвижение, подбор добычи и прокачка пока не реализованы.**

## Как проверить

1. Распакуй **весь ZIP** в отдельную папку, например `C:\PiratiaBots`.
   Внутри должны быть `Start-Bot.cmd` и папка `src`. В папки сервера ничего копировать не нужно.
2. Запусти свой сервер привычным способом: AccountServer, GroupServer, GateServer,
   GameServer для нужной карты. Настройки рабочего сервера менять не требуется.
3. Для теста нужен обычный **отдельный игровой аккаунт** с уже созданным персонажем.
   Создать персонажа можно один раз в обычной игре. Выйди этим аккаунтом из игры перед запуском бота.
   GM-права боту не нужны. Персонажа лучше оставить в безопасном месте Аргента.
4. Дважды нажми `Start-Bot.cmd`.
5. Если написано, что Python не найден: установи **Python 3.12 для Windows**
   с https://www.python.org/downloads/windows/ . В установщике отметь
   **Add python.exe to PATH**. После установки снова открой `Start-Bot.cmd`.
6. Введи логин игрового аккаунта бота и нажми Enter. Введи пароль и нажми Enter.
   **Пароль при вводе не виден — это нормально.** Для первой проверки используй логин
   и пароль из английских букв/цифр. Это игровые данные, не логины SQL `PiratiaGame/PiratiaAccount`.
7. Если на аккаунте несколько персонажей, введи номер нужного. При одном персонаже
   программа выберет его автоматически.

При успехе появится **«Сервер подтвердил вход в мир»**. Можно найти этого персонажа
своим основным аккаунтом в обычной игре. Бот не открывает `Game.exe` и не требует
второго окна игры. Открыто только его небольшое окно консоли. Через 60 секунд
программа отправляет обычные команды выхода; раньше можно остановить её через Ctrl+C.

Если произошла ошибка, пришли **`bot-report.json`** из папки программы и текст
ошибки из окна. Пароль присылать не нужно. Отчёт содержит этап, номера/размеры пакетов
и код отказа сервера, без паролей, имён аккаунтов и содержимого сетевых пакетов.

Подключение в этой версии разрешено только к `127.0.0.1:1973`: запускай на том же ПК,
где работает сервер. Один запуск обслуживает одного персонажа. Не запускай несколько
копий для одного аккаунта.

## Что уже проверено, а что предстоит

Точное совпадение EXE/PDB проверено для предоставленных GateServer и GameServer.
Классические алгоритмы 3DES, B и Noise сопоставлены с выполнением соответствующих
функций **твоего GateServer.exe в эмуляторе x86**. Есть 11 автоматических проверок,
включая обмен с тестовым сервером: вход, активация шифрования, вход в карту, ping,
выход, отказ в доступе, пустой аккаунт и разбиение TCP-пакетов.

**На настоящем Windows-сервере эта программа ещё не проверена.** Это тест совместимости,
а не готовый игровой ИИ. Следующий этап зависит от результата этого запуска:
разбор объектов мира, координат и характеристик, затем движение и бой.

Программа не меняет SQL, серверные EXE/DLL/CFG или игровой клиент. Зависимостей Python
из интернета не скачивает. Для работы достаточно установленного Python 3.9+.

Для разработчика: `python -m unittest discover -s tests -v`.
Технические сведения и ограничения — в `PROTOCOL.md`.
