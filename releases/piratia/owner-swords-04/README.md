# Fix04 — два меча buba через настоящий вход в NPC SDK

Fix03 показывал READY, но разговор не вызывал выдачу. Fix04 вставляет короткую
проверку внутрь существующей функции MsgProc в NpcSdk.lua. Полный перезапуск
GameServer обязателен: подмена глобальной функции во время работы больше не нужна.
GetPlayerByName не используется. Уровень35 и профессия уже получены — не меняются.

1. Корректно останови ботов и **все GameServer**, как при обычном обслуживании.
   Сохрани игровую сессию; не закрывай консоль аварийно.
2. Распакуй новый архив в новую папку. Запусти **Install-Buba-Fix04.cmd**.
   Укажи папку **того GameServer, который действительно запускаешь**, например
   `C:\PKO138 + Tools\[1] GameServer` или его resource.
3. Установщик сделает резервные копии в `resource/owner-buba-backups`, добавит
   проверку в SDK и обновит известные старые версии BubaSwords.lua. Неизвестные
   изменения файла выдачи не перезаписываются. Данные аккаунтов и персонажей не меняются.
4. Запусти все GameServer обычной кнопкой. В окне сервера ищи строку:

   **BUBA04 SDK HOOK LOADED**

   Если строки нет, не продолжай выдачу: нужно проверить путь установки/перезапуск.
5. Войди за **buba**, освободи четыре ячейки обычной сумки. Поговори с НПС.
   Вводить &lua, повторно давать профессию или добавлять опыт **не нужно**.
6. В чате должно появиться **BUBA04 START**, затем **received 2...**.
   Если возникнет **BUBA04 ERROR**, пришли полный текст. При pending в состоянии
   выдачи не удаляй файл и не запускай повтор вслепую: часть вещей могла уже создаться.
7. После получения, если права ГМ ещё включены, выйди с аккаунта и выполни
   **Disable-GM-buba.sql** в SSMS, затем войди снова.

Меняются только наш скрипт выдачи, короткая вставка в SDK и, если его исходная
контрольная сумма подтверждена, соответствующая запись SDK в журнале магазинов.
Остальной SDK, NPC, магазины и их координаты сохраняются. Проверка выдачи действует
только для имени buba (без учёта регистра), затем обычный обработчик продолжает диалог.
Остальные игроки и боты ничего не получают.

Защита от дублей — прежний `resource/owner-buba-swords-01.state`. Он сохраняется при
обновлении. Перед созданием предметов записывается pending; успешная выдача отмечается done.
Ошибки не удаляют заработанные вещи. После слияния удаляются только две временные основы,
созданные именно текущим запуском.

Результат: два одноручных Assassin Sword1397,35уровень, в аппарели Crimson Thunder5002,
усиление15, Ярость9 + Глаз Чёрного дракона9 + Огненный самоцвет9. Итого +27 на каждом.
Расовые и профессиональные ограничения на ношение не обходятся.

Проверки:16локальных тестов; дополнительно вставка исполнена в присланном владельцем
NpcSdk.lua с моделью native API, без GetPlayerByName. Испытана миграция с опубликованного
Fix03, сохранение прежнего SDK, NPC и состояния выдачи. Реальная выдача в работающем
GameServer ещё не подтверждена. Старые BubaNPC.lua/прямые dofile-команды для01–03 больше не нужны.
