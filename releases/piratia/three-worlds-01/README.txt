Пиратия 1.38.1 — три основные локации

Установка:
1. Выйдите из клиента. В служебном окне каждого работающего GameServer введите Stop(10) и нажмите Execute. Дождитесь закрытия. Затем остановите GroupServer, GateServer и AccountServer через Ctrl+C в их консольных окнах. Не завершайте процессы через Диспетчер задач.
2. Распакуйте все файлы комплекта прямо в C:\PKO138 + Tools, рядом с папками [1] AccountServer, [1] GameServer и т.д.
3. Один раз запустите Setup-Worlds.bat. Должно появиться READY. При ERROR не продолжайте: сохраните сообщение.
4. Запустите Start-All.bat. При последующих запусках нужен только этот файл.

Что меняется:
- Создаются GameServer2.cfg (magicsea) и GameServer3.cfg (darkblue), имена экземпляров GameServer01 и GameServer02. Исходный GameServer.cfg с garner не меняется.
- Доступ к SQL копируется из вашего локального GameServer.cfg, в комплекте нет ваших паролей.
- В [bird] GroupServer.cfg добавляются Аргент, Шайтан и Ледынь. Существующие английские названия сохраняются. Запись выполняется в Windows-1251.
- Перед изменением GroupServer.cfg и существующих дополнительных CFG создаются резервные копии.
- Запускатор открывает AccountServer, GroupServer, GateServer и три экземпляра GameServer с правильными рабочими каталогами. Проверяет локальные порты и отказывается запускать дубликаты. SQL Server должен быть запущен заранее.

Проверка:
В трёх окнах GameServer должны быть GameDB: ok, Gate: connected и соответствующая карта garner / magicsea / darkblue со статусом ok. Сам запуск процесса ещё не подтверждает загрузку карты. Протестируйте персонажей из Аргента, Шайтана и Ледыни.

Ограничения:
Это подключение только трёх основных миров. Подземелья и остальные отдельные карты ещё не включены. Комплект рассчитан на уже работающую сборку и исходный GameServer.cfg с одной картой garner. Реальный запуск Windows/игровой вход в новые локации в среде автора не проверены. Все процессы продолжают работать, пока вы их корректно не остановите.
