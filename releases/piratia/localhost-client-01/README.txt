Пиратия 1.38.1: подключение к локальному серверу

1. Сделайте резервную копию scripts\table\ServerSet.bin в папке клиента.
2. Замените его файлом ServerSet.bin из этого комплекта.
3. Файл start-local.bat положите в корень клиента рядом с Piratia.exe.
4. Учётную запись игрока нужно создать отдельно; логины SQL не являются игровыми аккаунтами.

В трёх исходных записях заменены только шесть IP-адресов на 127.0.0.1. Названия серверов оставлены исходными; все три ведут на локальный компьютер.
Размер и остальные байты таблицы сохранены. Проверка входа через настоящий клиент ещё не проведена.
