# Alpha88. Единый предел уровня мобов в шахтах и на других картах

Обычная охота использует верхнюю границу «уровень бота +3». Ограничение
действует при выборе лагеря, оценке поездки и перед боем по текущему
уровню цели, который прислал сервер. Прошлые победы, квестовая цель
и недавний урон от моба больше не позволяют обойти эту границу.

В третьем ярусе рудника есть известные стоянки мобов 35, 36 и 38 уровней.
Бот 36-го уровня может качаться на них. Тыквенный рыцарь 46-го уровня
попадает в допустимый диапазон начиная с 43-го уровня персонажа,
если подходит по остальным условиям. Если в ярусе нет лагеря в
допустимом диапазоне, бот может воспользоваться известным выходом
в соседний ярус. На маршруте подтверждаются штатные переходы сервера.

Для обновления остановите ботов, распакуйте Alpha88 Complete в новую
папку, скопируйте в неё всю рабочую папку data и запустите Start-World.cmd.
Установленная серверная ревизия 60 подходит. Проверки выполнены вне игры.
