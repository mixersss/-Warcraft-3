# Alpha74. Координаты мобов и возврат к охоте

В присланных серверных ресурсах подтверждено соответствие карт файлам
размещения через список mlist.lua. В справочник добавлены 3 503 записи
размещения на девяти картах. У 41 сухопутного вида впервые появились
координаты. Охотничьи маршруты используют эти координаты, если с
проверенной высадки есть сухопутный проход к лагерю и там разрешён бой.
Подходящие цели оцениваются по силе персонажа, риску и опыту за время боя.

Например, у входа на первый этаж Башни Одиночества теперь известны
координаты Mad Tribal Witchdoctor, Frenzied Lizardman и Nimble Forest
Hunter 69-го уровня. Отдельная площадка второго этажа ведёт к Nimble
Shadow Hunter и Terra Soldier Leader 71-го уровня и Elite Terra Warrior
72-го. Проверены проходимость лагерей и принадлежность нужному этажу.
Переход в игре требует нативного портала или билета. Если после
пяти минут без опыта обычного маршрута не нашлось, один бот с обратным
билетом может проверить известную условную точку на острове. Пока
сервер не покажет моба, это разведка. Для одной высадки действует
общий получасовой интервал. Через три минуты без опыта разведчик
ищет обратный путь.

## Цикл охоты

- Когда для обязательной покупки не хватает золота, бот временно
  выбирает слабых мобов для заработка. Если рядом нет безопасных мобов
  до 12-го уровня, допустимы более высокие безопасные цели на его суше.
  Бот продаёт пачкули при нехватке денег без ожидания полной партии.
  После подтверждения продажи и достижения нужной суммы продолжает
  покупку, а затем охоту. Сохранённая точка лагеря может быть
  переиспользована, пока она остаётся доступной и подходит для цели.
- При заполнении сумки бот продаёт пачкули и разрешённые обычные трофеи
  доступному NPC. Защищённые вещи и квестовые предметы сохраняются.
- Когда фея голодна, корм из любой ячейки можно использовать на месте.
  При отсутствии корма сохраняется покупка через NPC. После
  подтверждения ухода бот возвращается к своей обычной работе.
- После гибели моба задержка предыдущего действия сбрасывается.
  Следующая доступная цель проверяется сразу. Нативные подтверждения,
  перезарядка, запретные зоны и обычная скорость ударов сохраняются.

## Как добавить координаты с установленного сервера

Если путь к resource уже сохранён, при запуске боты читают
поддерживаемые таблицы размещения текущего сервера и его список
скриптов запуска. Для ручного выбора пути запустите
IMPORT-SERVER-SPAWNS.cmd в новой папке ботов и укажите папку resource.
Импорт читает таблицы ChaSpn.txt и распознанные вызовы в скриптах
запуска. Он сохраняет свой справочник в data атомарно.
Исходные файлы сервера сохраняются.

При двух отдельных подтверждённых боях с фактическим приростом опыта
общий локальный справочник запоминает место, если подходящая
координата ещё отсутствует. Это даёт ботам путь к новым местам, о
которых узнал другой бот. Справочник хранится в data. Для 115 сухопутных
видов в приложенных источниках пока нет привязки к координатам.
Появление по условиям всё ещё требует данных конкретного сервера или
наблюдения в игре. Квестовые цепочки и подземелья с неизвестными
условиями доступа требуют отдельной проверки.

## Обновление

Остановите ботов. Распакуйте Alpha74 Complete в новую папку и
перенесите всю прежнюю папку data. Запустите Start-World.cmd. Для
обновления подходит установленная серверная ревизия 60. Изменения
проверены локально. Частота прокачки на живом сервере не измерялась.
