# Установка Alpha61

Если серверный патч Alpha60 уже установлен:

1. Останови только ботов. GameServer и игру выключать не нужно.
2. Распакуй Alpha61 в новую папку. Старую папку сохрани.
3. Скопируй **всю папку data** из действующей версии в новую.
4. Запускай ботов из новой папки. В отчётах будет AutoAccountsAlpha61.

INSTALL-SERVER-SHOPS повторно для перехода60→61 запускать не нужно.
Серверная часть в комплекте осталась60; цены, карты и рейты не менялись.
Если сервер ещё старее60: останови ботов, GameServer и клиент, перенеси data,
запусти INSTALL-SERVER-SHOPS.cmd, затем перезапусти сервер, клиент и ботов.

Через10–15 минут проверь:

- population-status.json: реальный прирост опыта и атаки.
- Find-Bot / Show-Bot-Diagnostics: «Координаты кача», hunt.hunting_coordinates.
- Мореплаватели: coral в необходимом слоте, активный214 и cast_requests растёт;
  confirmed_equips не должен непрерывно увеличиваться без боя.
- Маги: подходящий посох, активный Bolt, реальные атаки и native_xp_delta.
- repair: estimated_funding_needed, native_prequote_refusals,
  confirmed_repairs; недостаток денег не должен вызывать вечные визиты.

Если снова заметен простой, пришли population-status.json и2–3 свежих
bot-report-N.json. Полную data с аккаунтами присылать не нужно.
Время и условия живой массовой прокачки пока не подтверждены.
