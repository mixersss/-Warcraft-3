# Alpha87. Готовые координаты лагерей мобов

Бот заранее выбирает сухопутного моба по уровню, ожидаемому опыту и
доступности лагеря. Он идёт к координатам спавна из серверных таблиц
или к ранее подтверждённой точке. Морские мобы исключены из обычной
прокачки. В поставляемых таблицах проверено 16 829 наземных боевых
точек для 226 видов мобов с опытом на девяти картах.

При планировании поездки бот заранее проверяет лагеря для каждого
возможного места высадки. Когда сервер подтвердит перемещение,
бот использует точки, доступные от фактического места высадки.
Он может выбрать одну из трёх разнесённых точек, если они есть.
При пустом лагере или недоступном пути бот переключается на другой
известный лагерь. Заброшенная шахта 1 остаётся исключена из прокачки
по сообщению владельца о её пустых залах.

При восстановлении знаний о магазинах подтверждённый путь к
GameServer/resource запоминается для чтения фактических расстановок
мобов. Точные серверные координаты сохраняются даже при ограничении
выборки для больших прямоугольных зон. Карты с условными спавнами,
для которых нет подтверждённых координат, исключены из поездок
за опытом. Полнота зависит от доступных файлов сервера и известных
точек появления событийных мобов.

Для обновления остановите ботов, распакуйте Alpha87 Complete в новую
папку, скопируйте в неё всю рабочую папку data и запустите Start-World.cmd.
Установленная серверная ревизия 60 подходит. Проверки маршрутов
выполнены вне игры. Темп прокачки на работающем сервере ещё предстоит
измерить.
