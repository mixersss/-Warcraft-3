## Установка поверх предыдущего патча

1. Останови ботов и GameServer, закрой клиент Game.exe. Сохрани копию своей `data`.
2. Скопируй содержимое единого комплекта Alpha48 поверх папки ботов,
   сохраняя `data`. Промежуточные версии не требуются.
3. Запусти корневой **INSTALL-SERVER-SHOPS.cmd**. Укажи серверную папку
   GameServer/resource, затем папку клиента Пиратии, где находятся `scripts`.
   Координаты вводить не нужно.
   Например, сервер: `C:\PKO138 + Tools\[1] GameServer\resource`;
   клиент: `C:\Games\Пиратия Online`. Это разные папки. Во второй строке
   нельзя снова указывать серверную resource: нужен клиентский scripts/table/iteminfo.bin.
4. Установщик обновит сервер, цены в клиенте и справочник новых НПС для ботов,
   сделает резервные копии. Запусти сервер, клиент и затем ботов.
5. У каждого нового НПС выбери **Trade**. Для аппарелей также проверь остальные
   наборы Trade - part2…8. НЯ/ЗЯ находятся у Experience and Luck.

**Клиент тоже нужно обновить.** Обычное окно торговли берёт цену из своего
ItemInfo.bin, а сервер списывает по серверному ItemInfo. Поэтому меняются цены
выбранных646ID (645товаров магазинов и Пачкули) и в серверных таблицах, и в клиентской. Эти цены действуют
у всех обычных НПС для тех же предметов, включая их родную оценку при продаже.
Имена, модели, эффекты, ограничения, остальные цены и параметры сохраняются.
Не копируй серверный ItemInfo.bin поверх клиентского: установщик правит только
нужные поля в собственном файле клиента и сохраняет русские названия/модели.
Для остальных игроков есть **UPDATE-CLIENT-PRICES.cmd**: он обновляет только клиент.

При обновлении01/02/03→04 изменения вне нашего блока Lua сохраняются. Установщик
сверяет сам блок01 с известным исходным кодом, проверяет точку подключения
в SDK и существующие пять НПС. Если изменён наш блок или нарушены привязки,
установка останавливается с указанием причины. При обновлении02(Alpha47/Fix01)→03сверяются сохранённый каталог, точный блок
нашего кода, обработчики SDK и все пять привязок НПС. Посторонние изменения
вне этих блоков сохраняются. Неизвестная версия не перезаписывается.
Повторная установка готового патча
не размножает НПС. Нельзя запускать старый установщик City Shops01 поверх02.

## Что изменяется и как откатить

Сервер: только NpcScript01.lua, NpcSdk.lua, garnernpc.txt/garnerNPC.bin,
ItemInfo.txt/ItemInfo.bin. При переходе с01 существующие157записей НПС
сохраняются побайтно. В ItemInfo изменяется только поле цены выбранных ID.
Клиент: только цены тех же ID в scripts/table/iteminfo.bin.
Ботам добавляется assets/owner-city-shops.json с реальными ассортиментами,
ценами, координатами и номерами наборов. Аккаунты, персонажи, SQL, рейты,
награды за квесты и `data` не редактируются.

Резервные копии находятся в resource/owner-city-shops-backups/v2-<дата>/.
restore-index.json показывает исходный путь каждого файла и его резервную копию.
Если backup=null, это новый справочник ботов, которого прежде не было.
Для ручного отката останови сервер/клиент/ботов, верни файлы по этому индексу,
убери созданный справочник при backup=null и контрольный owner-city-shops-v2.json.
Старые резервные копии City Shops01 сохраняются.
