Naruto Ultimate RPG 4.2i — Clean rebuild 0.2
Исходная карта: ShikamaruShadow. Авторство внутри карты сохранено.

Это новый MPQ-архив, полностью собранный из распакованных файлов присланной карты.
Старые сжатые блоки и шифрование не копировались. Исходные модели, текстуры,
анимации, звуки, музыка, ландшафт, предметы, способности и сюжет перенесены.

ФАЙЛЫ
Naruto_4_2i_Clean_NoAI_02.w3x — сначала проверьте эту копию.
В ней исходный сюжетный скрипт сохранён побайтово, новые боты не добавлены.
Она нужна для проверки, что новая упаковка открывается в Warcraft III 1.26.

Naruto_4_2i_Clean_Bots_02.w3x — та же новая упаковка с ранее подготовленным
тестовым ИИ первой локации: прокачка, боевые навыки, подбор добычи, атака Забузы.
Слоты ботов нужно назначить компьютерами в лобби. Люди не управляются новым ИИ.
Автоматическое прохождение остальных сюжетных этапов и покупки пока не добавлены.

УСТАНОВКА
Положите .w3x в Maps\Download. Для проверки создайте свою игру в Warcraft III 1.26.
Внутреннее название карты сохранено. Отличайте новые копии по имени файла.
Предыдущие версии Bots_01, Bots_01a и Load_Test_01a больше не используйте.

ЧТО ВОССТАНОВЛЕНО
- Обычный MPQ версии 0 с секторами 16 КиБ, без SINGLE_UNIT и шифрования.
  При секторах 4 КиБ карта выходила за сетевой лимит Classic 8 МиБ.
- Корректные размеры архива и таблицы контрольных сумм для всех файлов.
- Обычная структура war3map.w3i: все 12 игровых слотов, 4 команды по 3 игрока,
  правильные битовые маски команд и завершённые таблицы настроек.
- Восстановлен список известных имён ресурсов (459 имён, 454 разных файла).
  Файлы с неизвестными именами тоже полностью перенесены с исходными хешами имён.
- Сюжетный JASS доступен также по обычному корневому пути war3map.j.

СОХРАННОСТЬ РЕСУРСОВ
Все 461 исходный файл удалось извлечь. Их CRC32 совпадают с исходными данными.
Во вновь собранных картах проверены побайтово 67 моделей MDX, 200 текстур BLP
и 174 файла WAV/MP3. Встроенные в модели анимации и ссылки на текстуры сохранены.
Изменены только служебные данные архива, список имён, данные лобби и, в версии
Bots_02, добавленный ранее модуль ИИ. Существующий сюжет не переписывался.

ПРОВЕРКИ И ОГРАНИЧЕНИЯ
Все 461 файла в обеих картах прочитаны нативной StormLib, проверены контрольные
суммы и хеши содержимого. Чтение и распаковка независимо проверены на Python
для 454 файлов с восстановленными именами. Новый архив также проверен JS-парсером.
Обе карты меньше 8 МиБ. Данные лобби проходят строгий разбор без обрезанных полей.
Синтаксис игрового скрипта и 75 проверок логики ИИ проверялись отдельно.

Это всё ещё не подтверждает запуск в самом Warcraft III: движка игры здесь нет.
Требуется проверить выбор карты, загрузку, модели/музыку и переходы сюжета в 1.26.
Исходные визуальные триггеры редактора удалены авторской защитой: создание нового
архива их не восстанавливает. Обычное пересохранение в World Editor может заменить
ручной сюжетный JASS. Для дальнейших правок нужен сохранённый скрипт и сборщик.
