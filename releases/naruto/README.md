# Naruto Ultimate RPG 4.2i — Story Bots 0.1a

[Скачать исправленную карту 0.1a](https://github.com/mixersss/-Warcraft-3/raw/refs/heads/main/releases/naruto/Naruto_4_2i_Bots_01a.w3x) · [Проверочная копия без ИИ](https://github.com/mixersss/-Warcraft-3/raw/refs/heads/main/releases/naruto/Naruto_4_2i_Load_Test_01a.w3x) · [Архив с инструкцией](https://github.com/mixersss/-Warcraft-3/raw/refs/heads/main/releases/naruto/Naruto_4_2i_Bots_01a_Package.zip)

Версия 0.1 вызвала у пользователя «The file data is corrupt» при выборе карты. В 0.1a обновлена CRC32 скрипта в служебном файле `(attributes)` и нормализован размер заголовка MPQ (32 байта вместо защитного нестандартного значения). Новые проверки обнаруживают эти дефекты в опубликованной 0.1 и проходят для 0.1a. **Устранение ошибки в настоящем Warcraft III ещё не подтверждено.** Прежнюю 0.1 использовать не рекомендуется.

Игровой скрипт относительно 0.1 не менялся. Это тестовый ИИ **только первой локации**, до письменного экзамена. Автор исходной карты — ShikamaruShadow. Все 459 блоков игровых ресурсов сохранены побайтово; изменены скрипт и его запись в служебной таблице контрольных сумм.

Положите `.w3x` в `Maps\Download` Warcraft III 1.26 и назначьте нужные слоты компьютерами. Ботам добавлены прокачка на местных врагах, навыки, подбор добычи и выход к своему Забузе в последние 90 секунд. Следующие сюжетные этапы и покупки пока не автоматизированы.

Проверки: JASS Classic, 75 условий логики с имитацией функций движка, два MPQ-парсера, CRC32 скрипта, границы файлов и таблиц архива. Реальные загрузка, бой и маршруты требуют проверки в игре.

Подробности: [README_RU.txt](README_RU.txt). Контрольные суммы: [SHA256SUMS](SHA256SUMS).
