# Naruto Ultimate RPG 4.2i — Clean rebuild 0.2

[Новая упаковка без ИИ — проверить первой](https://github.com/mixersss/-Warcraft-3/raw/refs/heads/main/releases/naruto/Naruto_4_2i_Clean_NoAI_02.w3x) · [Новая упаковка с тестовыми ботами](https://github.com/mixersss/-Warcraft-3/raw/refs/heads/main/releases/naruto/Naruto_4_2i_Clean_Bots_02.w3x) · [Обе карты и инструкция](https://github.com/mixersss/-Warcraft-3/raw/refs/heads/main/releases/naruto/Naruto_4_2i_Clean_02_Package.zip)

Пользователь подтвердил, что исходная карта открывается в Warcraft III 1.26, а обе изменённые 0.1a дают «The file data is corrupt» уже при выборе. По его запросу версия 0.2 собрана **в полностью новом MPQ-архиве** из всех распакованных файлов. Старые сжатые блоки и шифрование не копировались. Предыдущие 0.1/0.1a заменены этой тестовой сборкой.

Автор исходной карты — ShikamaruShadow. **Перенесены именно оригинальные персонажи:** 67 моделей, 200 текстур и 174 WAV/MP3 проверены побайтово. Анимации в моделях, музыка, ландшафт, предметы, способности и существующий сюжет сохранены. Все 461 исходный файл извлечены с правильными CRC32.

Используется стандартный MPQ версии 0 без шифрования и SINGLE_UNIT, с секторами 16 КиБ. При 4 КиБ карта выходила за сетевой лимит Classic; новые файлы ~7,84 МБ, меньше 8 МиБ. Восстановлены данные лобби (12 слотов, 4 команды по 3), список известных имён и корневой путь `war3map.j`.

**Сначала проверьте Clean_NoAI_02:** она содержит исходный сюжетный скрипт побайтово. Clean_Bots_02 содержит ранее подготовленный ИИ только первой локации — прокачка, навыки, подбор добычи и атака Забузы. Следующие сюжетные этапы и покупки ботами пока не автоматизированы.

Все файлы обеих карт прочитаны и проверены нативной StormLib; восстановленные имена независимо проверены Python-парсером, весь архив — JS-парсером. **Запуск в самом Warcraft III ещё не подтверждён.** Установите `.w3x` в `Maps\Download` и создайте игру; для Bots назначьте нужные слоты компьютерами.

Новый архив не восстанавливает удалённые визуальные триггеры World Editor. Обычное пересохранение в редакторе может заменить ручной сюжетный JASS; дальнейшие изменения требуют сохранённого скрипта и сборщика.
